## What's new?

This release adds more filters to Sniffies' own filter menu, and reorganizes the premium-feature overrides into one section. The features are now two groups, each with sub-features.

### Profile Filters

Sniffies' filter menu only goes so far. Profile Filters adds more filters to the Cruisers section of the Map Layers menu, built to look and feel like the ones Sniffies already has.

- **Gender:** an on/off switch with Male, Female, Nonbinary and Not specified buttons. Pick as many as you like; at least one always stays selected.
- **Height and Weight:** new lines under Cruiser Stats that open a min/max range sheet. You can set only a minimum, only a maximum, or both. Units follow your locale (ft/lb or cm/kg), and you can choose whether to also show profiles that don't list the value at all. If you turn Cruiser Stats off, both filters grey out and switch off, and they come back with their ranges intact when you turn it on again.

- **Last Online:** a row under Cruising Now with a "Select" button that opens a scrolling sheet from 15 minutes up to 48 hours, plus a toggle. It stores a rolling window ("less than 15 min ago") rather than a fixed cutoff time, so it stays true as time passes. People stay on the map after they go offline, until you reload.

- **No cap on Sexuality, Body Type and Position:** Sniffies limits these to "Choose up to 3" (4 for Position). With Profile Filters on, the limit is raised to 99.

Filters apply to the map only. Your chats are never hidden by Gender, Height, Weight or Last Online.

### Premium Features

Location spoofing, opening profiles outside your free radius, and hiding sent photos used to be three separate sections. They now live in one Premium Features section with a master toggle and a switch per sub-feature. Your old settings carry over. The extension also detects paid Sniffies Plus accounts, and if you have one it tells you that you don't need these.

- **Location spoofing:** override the GPS coordinates Sniffies sees, so you can browse the map from anywhere.
- **Profiles outside your free radius:** click profiles beyond the free geofence to view them without hitting the paywall.
- **Hide sent photos without the paywall:** clicking "Hide Photo" or "Unhide Photo" on a photo you sent now does it instead of showing the paywall, and the page reloads so the photo shows as hidden. "Hide all Photos" and "Unhide all photos" in the profile menu work the same way. This works in all three install options.

## How do I use these features?

**Profile Filters:** open the "Profile Filters" section of the popup (Chrome extension) or panel (userscript, bookmarklet) and click "Enable". It is off by default. Then open the Cruisers section of Sniffies' Map Layers menu to find the new rows.

Gender, Height, Weight and Last Online work by filtering Sniffies' network responses as the page loads, so changes need a page reload to take effect. When you change one, a "Reload to apply" button appears right on that row.

**Premium Features:** open the "Premium Features" section, turn on the master toggle, then switch on the sub-features you want. Profiles outside your free radius and hiding sent photos need nothing else; for location spoofing, enter coordinates and save.

| Feature                                                   | Chrome extension | Userscript | Bookmarklet |
| --------------------------------------------------------- | ---------------- | ---------- | ----------- |
| **Profile Filters**                                       |                  |            |             |
| &nbsp;&nbsp;↳ Gender, Height, Weight, Last Online         | Yes              | Yes        | No          |
| &nbsp;&nbsp;↳ Raised Sexuality / Body Type / Position cap | Yes              | Yes        | Yes         |
| **Premium Features**                                      |                  |            |             |
| &nbsp;&nbsp;↳ Location spoofing                           | Yes              | Yes        | No          |
| &nbsp;&nbsp;↳ Profiles outside your free radius           | Yes              | Yes        | Yes         |
| &nbsp;&nbsp;↳ Hide / unhide sent photos                   | Yes              | Yes        | Yes         |

A bookmarklet only runs after the page has loaded, so it is too late to filter the initial map data. It gets the raised selection caps, and the userscript is the way to get the rest on iOS.

## Other changes

- Versions of the Chrome extension, userscript, bookmarklet and server are now all 0.4
- Added a `yarn format` command in the repo that runs Prettier in every package
- Verified the bookmarklet install works
- Fixed a Prettier issue
- The network filtering code is now one shared layer that the bot blocking and the new filters both use, and Sniffies' API paths and payload shapes are defined in one place. If Sniffies changes its data format, the console now warns about which expected field is missing.
