## What's new?

This release adds more filters to the Sniffies filter menu. Someone on the sniffies subreddit also posted about how they felt like being able to hide sent pictures should be a free feature. After my experience building around the free user radius, I felt like this would be another premium feature I could tackle. Now with 3 premium features added, I felt like reoragnizing this set of features under a single "premium features" section. I have more ideas for working within this space, but thats for 0.5, or the 1.0 release post, whichever comes first.

### Profile Filters

The Sniffies filter menu only goes so far. My Profile Filters add more filters to the Sniffies filter menu, built to look and feel like the ones Sniffies already has.

- **Gender:** an on/off switch to show Male, Female, Nonbinary, or gender Not specified. Pick as many as you like; at least one must be selected.
- **Height and Weight:** new filters under "Cruiser Stats". You can set only a minimum, only a maximum, or both. Units follow your locale (ft/lb or cm/kg), and you can choose whether to show profiles that don't list a value at all.

- **Online After:** a filter similar to "Cruising Now". I don't like how the "Crusing Now" setting is so jittery, profiles show up and disappear as guys log on and off. Users can choose a lookback period of time between 15 minutes ago to 48 hours ago. When a lookback is choosen and the page is reloaded, only profiles online more recently than the selected point in time will be shown. The selected time does not roll forward (Choosing 15 min ago at 8:00PM will filter for profiles online after 7:45PM. At 8:30PM, the project will still be filtering for profiles online after 7:45PM).

- **No cap on Sexuality, Body Type and Position:** Sniffies limits these to "Choose up to 3" (4 for Position). But, the number of selected values is ultimately arbitrary. With Profile Filters on, the limit is raised to 99 (arbitrarily high value).

Filters apply to the map only, just like Sniffies filters do. Your chats are never hidden by Gender, Height, Weight or Online After.

### Premium Features

Location spoofing, opening profiles outside the free radius, and hiding sent photos used to be three separate sections. They now live in one Premium Features section with a master toggle and a switch per sub-feature. The extension also detects paid Sniffies Plus accounts, and if you have one it tells you that you don't need these.

- **Location spoofing:** override the GPS coordinates Sniffies sees, so you can browse the map from anywhere.
- **Profiles outside your free radius:** click profiles beyond the free geofence to view them without hitting the paywall.
- **Hide sent photos without the paywall:** clicking "Hide Photo" or "Unhide Photo" on a photo you sent now does it instead of showing the paywall, and the page reloads so the photo shows as hidden. "Hide all Photos" and "Unhide all photos" in the profile menu work the same way. This works in all three install options.

## How do I use these features?

**Profile Filters:** open the "Profile Filters" section of the popup (Chrome extension) or panel (userscript, bookmarklet) and click "Enable". It is off by default. Then open the Cruisers section of Sniffies' Map Layers menu to find the new rows.

Gender, Height, Weight and Online After work by filtering Sniffies' network responses as the page loads, so changes need a page reload to take effect. When you change one, a "Reload to apply" button appears right on that row.

**Premium Features:** open the "Premium Features" section, turn on the master toggle, then switch on the sub-features you want. Profiles outside your free radius and hiding sent photos need nothing else; for location spoofing, enter coordinates and save.

| Feature                                                   | Chrome extension | Userscript | Bookmarklet |
| --------------------------------------------------------- | ---------------- | ---------- | ----------- |
| **Profile Filters**                                       |                  |            |             |
| &nbsp;&nbsp;↳ Gender, Height, Weight, Online After         | Yes              | Yes        | No          |
| &nbsp;&nbsp;↳ Raised Sexuality / Body Type / Position cap | Yes              | Yes        | Yes         |
| **Premium Features**                                      |                  |            |             |
| &nbsp;&nbsp;↳ Location spoofing                           | Yes              | Yes        | No          |
| &nbsp;&nbsp;↳ Profiles outside your free radius           | Yes              | Yes        | Yes         |
| &nbsp;&nbsp;↳ Hide / unhide sent photos                   | Yes              | Yes        | Yes         |

A bookmarklet only runs after the page has loaded, so it is too late to filter the initial map data. It gets the raised selection caps, and the userscript is the way to get the rest on iOS.
