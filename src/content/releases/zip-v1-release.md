I like some of the LinkedIn daily games, especially Zip. But some days, despite LinkedIn's best efforts to remind me to play my dailies, I forget.

To fix this problem, I've rebuilt Zip: https://zip-clone.vercel.app/

It was a lot of fun building this project largely using Claude. It's crazy how fluidly I can express an idea and get back some code that perfectly captures what I'm looking for.

If anyone is actually interested in this project, I plan to add leaderboards as a next step.
